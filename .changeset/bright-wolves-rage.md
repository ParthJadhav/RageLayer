Rename the package and project to RageKit. The React and Vue components are now `RageKit`, lifecycle helpers are `createRageKit`, `mountRageKit`, and `useRageKit`, the Svelte action is `rageKit`, and the custom element is `<rage-kit>`. Package-prefixed DOM attributes, events, constants, and development environment variables now use the `ragekit` or `RAGEKIT` prefix.
