# Examples

Minimal, runnable starters for each stack. Their lockfiles use the latest published
`ragelayer`, while the local setup commands replace it with the package built from
this checkout so changes under review are exercised too.

| Example | Stack | Shows |
| --- | --- | --- |
| [`nextjs`](./nextjs) | Next.js App Router | The React component behind a client-side trigger |
| [`nuxt`](./nuxt) | Nuxt 3 | The Vue component and the headless composable |
| [`sveltekit`](./sveltekit) | SvelteKit | The custom element, with no framework wrapper |
| [`vanilla`](./vanilla) | No framework | `createRageLayer` plus a custom toolbar |

Each directory has its own README with the exact commands.
