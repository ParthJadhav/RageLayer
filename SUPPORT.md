# Support

- Use [GitHub Discussions](https://github.com/ParthJadhav/desktop-destroyer/discussions) for setup
  questions, integration help, and ideas.
- Use the [bug report form](https://github.com/ParthJadhav/desktop-destroyer/issues/new?template=bug_report.yml)
  for a reproducible defect.
- Use [private vulnerability reporting](./SECURITY.md) for security concerns.

Before asking for help, check the [documentation](https://parthjadhav.github.io/desktop-destroyer/),
search existing issues, and try the latest package version. A minimal reproduction and browser
details make visual/capture bugs much easier to diagnose.
